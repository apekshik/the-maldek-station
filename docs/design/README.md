# Station design direction

[Station systems, machinery, records and sound](station-systems-research.md) records the September 7, 2026 discussion against the R12 station baseline. It includes accepted creative direction, proposals still to resolve, and manufacturer references. It supplements the older GDD; it does not claim that the proposed gameplay or model changes are implemented.

The selected drive reference is page 13 of [Doppelmayr WIR 202](references/Doppelmayr-WIR202-drive-reference.pdf). The source URL and usage context are recorded in the research note. The PDF is retained for reference, not licensed for redistribution as game content.

[Former passenger cabin](passenger-cabin.md) and its [interactive review plan](../passenger-cabin.html) define the September 9 proposed L-shaped replacement: quantities, circulation, inspection sequence and Blender build order. Layout review only; site fit remains to verify.
