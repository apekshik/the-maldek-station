# R04 Unreal integration

Open `game/game.uproject`, then `/Game/MaldekRefinement/Maps/BlockOut_R04`.
The original `/Game/BlockOut` remains unchanged. The project startup/default maps have not been changed by this integration.

## Included

- Fifteen evaluated Blender mesh sections: platform, control room, waiting hall, lower drive, generator, stairs, overlook, yard, arrival, doors, gondola, roofs and supports. Original Blender source remains editable and unchanged.
- 216 authored convex collision hulls, kept separate from decorative bolts, rail patterns and instruments. Metre-to-centimetre conversion and axis orientation verified using an asymmetric test mesh.
- Unreal materials for the station. Existing concrete and painted-metal textures are reused; procedural Blender bump and layered finishes are only approximated in this first pass.
- Existing gondola Blueprint and spline preserved. The new cabin is attached to its original movement component; the original cube component is invisible and has no collision.
- A 128 × 128 m supplemental terrain mesh around the station, built from 4,225 samples of the existing landscape. The arrival apron is 14.5 cm below the lower floor. Broad shoulders transition into the existing landscape. It uses 32,768 triangles and static complex collision.
- The local terrain material reuses an existing Fab ground texture and Ultra Dynamic Sky's `Surface_Weather_Effects` function for snow and wetness. The original landscape, sky, weather and seven point lights are retained.

## Checks

`working_level_report.json` records the source map hash, replaced actors and placement. `import_report.json` records mesh scale and collision counts. `working_inventory.json` records the saved assembly.

`gondola_playtest.json` records an editor simulation in which the cabin travels to the far end and returns to its initial position. Travel/wait times were shortened only in the temporary simulation world; saved gameplay timing is unchanged.

`collision_review.json` contains floor traces and capsule clearance checks at nine representative locations, including the new arrival ground. These are sample checks, not a complete player-route test. `final_verification.json` records the environment/route preservation and accepted target of **2560 × 1440 at 60 FPS**. Performance at that resolution has not yet been benchmarked.

## Next refinement

The supplemental terrain is a first playable shape. Refine the approach route, ridge silhouette, drainage and retaining edges before placing trees. The snow/material transition at the perimeter needs an art pass. Existing lights retain their old positions and need a deliberate placement pass for the new rooms. The user's lamp pack has not been downloaded or added.

Doors are separate meshes but do not yet have interaction logic. Remaining cable/drive animation, foliage density, texture finishing, LODs and a packaged 1440p performance pass remain open. Some existing Megaplant PVE assets report an unsupported custom version when scanned by UE 5.7; check their compatibility before choosing them for foliage.

## Source and automation

Station source: `art/blender/revision_04_refinement/millford_v2_refinement_04.blend`.
Terrain source: `station_local_terrain.blend`, regenerated by `scripts/build_local_terrain.py` from `terrain_samples.json`.

Scripts operate on `/Game/MaldekRefinement`. Do not regenerate over manual edits without preserving them. `build_working_level.py` refuses to overwrite an existing working map. Run material creation in the full editor, not the Python commandlet. `review_session.py` is a temporary local editor dispatcher with no network listener and a 30-minute expiry; it is stopped after this review.
