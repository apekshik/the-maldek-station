# Project memory

Before creating, modifying, generating or importing architectural meshes, read
[Mesh authoring lessons](art/MESH_AUTHORING.md). Apply its surface-ownership,
opening-clearance and Unreal validation checks before calling a mesh complete.
This includes door/window reveals, layered walls, floors, beams and trim.

Keep confirmed lessons and their reproduction/evidence links in that document
when subsequent mesh work exposes a new failure mode. Distinguish diagnosed
geometry defects from rendering artifacts; do not record an untested workaround
as a general rule.
